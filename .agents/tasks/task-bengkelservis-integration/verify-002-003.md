## Perubahan yang Dibuat

### 1. Fix: Malformed href di sidebar Montir Lapangan (role 5)
**File:** `resources/views/layouts/app.blade.php`

**Masalah:** Anchor tag memiliki dua fragmen href yang digabung secara salah:
```
href="{{ route('montir-lapangan.tugas.index') }}"#tugas-home-service"
```

**Perbaikan:** Menghapus `"#tugas-home-service"` yang tidak valid, menggunakan route saja, dan menambahkan active state yang tepat:
```
href="{{ route('montir-lapangan.tugas.index') }}"
class="nav-link {{ request()->is('montir-lapangan/tugas*') ? 'active' : '' }}"
```

### 2. Fix: Orphan `<div class="nav-item">` tanpa konten di sidebar Petugas Service (role 3)
**File:** `resources/views/layouts/app.blade.php`

**Masalah:** Ada tag `<div class="nav-item">` yang dibuka tapi tidak ditutup dan tidak memiliki konten, diikuti oleh `<div class="nav-item">` berikutnya yang berisi link Pembayaran. Menyebabkan HTML tidak valid (nested divs tidak seharusnya ada).

**Perbaikan:** Menghapus div kosong yang tidak memiliki pasangan tutup maupun konten.

## Masalah yang Masih Perlu Perhatian

1. **Route `teknisi.rating.index` tidak dilindungi middleware:** Route `/teknisi/rating` tidak berada dalam grup middleware `role:4`, sehingga bisa diakses oleh siapa saja yang sudah login. Ini perlu diperiksa apakah disengaja atau perlu dipindahkan ke dalam grup middleware yang sesuai.

2. **DashboardTeknisiController menggunakan tabel lowercase `penugasanteknisi`** di query raw (`penugasanteknisi as p`) sementara model menggunakan `PenugasanTeknisi`. Di MySQL case-insensitive (Windows) ini tidak masalah, tapi di Linux bisa bermasalah. Perlu diperhatikan saat deployment.

3. **Sidebar Teknisi (role 4)** — Menu "Pekerjaan Saya" dan "Dashboard" mengarah ke URL yang sama (`/dashboard-teknisi`). Fungsional tapi bisa dioptimalkan.
